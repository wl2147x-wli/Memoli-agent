## Purpose

对主动修剪、上下文溢出恢复、历史与当前工具结果截断、异步摘要及摘要注入进行完整成本和质量评测，防止只看主 Agent token 而忽略压缩成本与缓存扰动。

## ADDED Requirements

### Requirement: 所有上下文变换均可追踪
系统 SHALL 为轮次限制修剪、token 限制修剪、纯文本压缩、旧半区丢弃、工具结果截断、Provider 溢出恢复、摘要生成和摘要注入记录独立事件或 Observation。

#### Scenario: 轮次上限触发
- **WHEN** 历史轮次超过配置上限并移除旧轮次
- **THEN** 系统 MUST 记录触发原因、前后轮数、前后消息数、估算 token、丢弃范围和摘要任务 ID

#### Scenario: 工具结果被截断
- **WHEN** 当前或历史工具结果超过限制
- **THEN** 系统 MUST 记录工具名、原始长度、保留长度、估算 token 变化和当前/历史截断类型

### Requirement: 压缩成本全量核算
系统 SHALL 将主 Agent、压缩摘要模型、记忆 flush、子代理和重试产生的所有模型 usage 归属到同一任务，并 SHALL 同时提供分项和总量。

#### Scenario: 异步摘要晚于主响应完成
- **WHEN** 摘要线程在根任务返回后才完成
- **THEN** 摘要 Generation MUST 仍与原 run 关联，并 MUST 更新该 run 的最终压缩成本或标记等待中的成本状态

#### Scenario: 摘要失败使用规则回退
- **WHEN** LLM 摘要失败并使用规则式摘要
- **THEN** 系统 MUST 记录失败原因、已消耗模型 token、回退策略和最终摘要长度

### Requirement: 压缩质量评测
系统 SHALL 使用带黄金事实、决策、约束、实体关系和工具结果依赖的长对话评测压缩后的保留质量。

#### Scenario: 早期事实后测
- **WHEN** 早期轮次中的关键事实被压缩且在后续任务中再次询问
- **THEN** 系统 MUST 计算事实召回率、错误事实率和无法回答率

#### Scenario: 工具调用链依赖
- **WHEN** 后续步骤依赖被压缩轮次中的工具输入或输出
- **THEN** 系统 MUST 评价工具链完整性和最终任务成功，不得只评价摘要文本相似度

### Requirement: 缓存扰动与恢复评测
系统 SHALL 将每次上下文重写标记为缓存边界，并 SHALL 比较压缩前、压缩当轮和压缩后若干轮的缓存比例与 TTFT。

#### Scenario: 批量压缩发生
- **WHEN** 一次压缩重写历史前缀
- **THEN** 系统 MUST 记录首个差异位置、缓存损失、压缩后首轮 TTFT 和恢复到稳定缓存水平所需轮数

### Requirement: 压缩策略可配置对照
评测系统 SHALL 支持至少比较不压缩、当前半区删除、纯滑动窗口、每轮滚动摘要、高低水位批量摘要以及保留近期工具链的批量摘要。

#### Scenario: 高低水位实验
- **WHEN** 配置达到高水位触发并压缩到低水位
- **THEN** 运行 MUST 记录阈值、实际触发点、压缩后占用、下一次触发间隔和摊销收益

### Requirement: 强制触发和真实负载场景
系统 SHALL 提供受控的小上下文窗口来稳定触发压缩，并 SHALL 另行在真实模型窗口与真实任务负载下验证结果。

#### Scenario: 受控压缩基准
- **WHEN** 运行离线压缩实验
- **THEN** 数据集 MUST 包含长多轮对话、固定大小工具结果、少轮超大消息和 Provider 溢出模拟

### Requirement: 压缩净收益报告
系统 SHALL 报告总 token 节省率、总成本节省率、成功任务单位成本、压缩延迟、缓存重建代价、事实保留率和任务成功率。

#### Scenario: 表面节省但总成本增加
- **WHEN** 主 Agent input token 降低但摘要调用与缓存损失导致总成本上升
- **THEN** 结果 MUST 判定为无净成本收益，并展示导致回退的分项
